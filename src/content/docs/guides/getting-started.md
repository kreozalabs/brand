The Kreoza brand toolkit helps to represent the brand with consistency and confidence. It is intended for use by all internal and external contributors.

## Determine your type of creative

Ask yourself a few questions to understand what your needs are. These questions can help you with that:

- Who is the main audience for the creative?
- What is the main purpose of the creative?
- How will this creative be used or displayed?
- Will this creative be directly linked to the main brand?

### Example Answers

- **Main Audience:** Developers and designers that want to create something related to Kreoza.
- **Purpose:** To provide them help with styling and brand usage.
- **Usage:** The creative will be displayed in a website, or a video.
- **Linkage:** Direct link to Kreoza main brand.

### Example Result

**Use default Kreoza branding to keep as consistent with the brand as possible.**

## Customization

**Keep in mind that a single style doesn't fit every use case—and it doesn't have to!**

Therefore, styling can be customized based on product pillar, use-case, and target audience.

For more information about how to customize styling, see [Customization](/guides/customization/).
