Customizing the brand toolkit allows you to adapt styling to specific product pillars, use-cases, and target audiences while maintaining brand harmony.

## Why customize?

Some projects need quiet, subtle styling, while others call for vibrant expression. Think of customization as choosing clothing appropriate for different occasions.

## When to customize?

Always start with the default Kreoza brand style. As your project evolves, it will become clear if custom styling is needed:

- **B2B / Professional Products:** Require clean, subtle, and distraction-free styling.
- **Community / Media Products:** Benefit from more expressive and vibrant branding.

## What to customize?

You can adapt typography, accent colors, and component themes. However, **the closer you stay to core brand foundations, the better**.

Always use the base Kreoza brand system as your starting point, making adjustments only when required by user experience or context.

## Examples

You might add custom UI modes for a product where color directly impacts user experience.

For instance, in a **productivity application**, focus is key. Since user aesthetic preferences vary, offering a few tailored themes allows users to customize their workspace without breaking brand consistency:

- **Minimalistic:** Low-contrast neutrals for deep focus.
- **Paper-like:** Warm, reader-friendly tones.
- **Stylish:** Vibrant accents for creative work.

_Note: Customization should always enhance the user experience, never detract from it._
